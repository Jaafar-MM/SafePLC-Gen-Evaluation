# SafePLC-Gen Evaluation

Evaluation patch repository for the **SafePLC-Gen** model.

## Overview

This repository contains **6 folders** split into:
- **DEXPI inputs** used to test the SafePLC-Gen model, and
- **PatchEvaluation outputs** generated by SafePLC-Gen for each corresponding input set.

## Folder layout

### Inputs (`DEXPI-*`)
These folders contain the files used as **inputs** to SafePLC-Gen:

- `DEXPI-Image` — image-based DEXPI inputs
- `DEXPI-PDF` — PDF-based DEXPI inputs
- `DEXPI-XML` — XML-based DEXPI inputs

### Generated outputs (`PatchEvaluation-*`)
These folders contain the **generated files** produced by SafePLC-Gen for the corresponding input folder:

- `PatchEvaluation-DEXPI-Image` — outputs for `DEXPI-Image`
- `PatchEvaluation-DEXPI-PDF` — outputs for `DEXPI-PDF`
- `PatchEvaluation-DEXPI-XML` — outputs for `DEXPI-XML`

## How to use

1. Choose an evaluation case from one of the input folders (`DEXPI-Image`, `DEXPI-PDF`, or `DEXPI-XML`).
2. Run the SafePLC-Gen model using the selected files as inputs.
3. Compare your generated results with the committed outputs in the matching `ParchEvaluation-*` folder.
